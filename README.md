# 🏥 Programa 5S - Hospital Municipal Dr. Nestor Piva

Landing Page institucional desenvolvida para apresentar o **Programa 5S** implantado no Hospital Municipal Dr. Nestor Piva, reunindo informações sobre a metodologia, auditorias, resultados, certificações, evolução dos setores e registro do programa.

O objetivo do portal é apresentar de forma clara, moderna e interativa toda a evolução do Programa, fortalecendo a cultura da qualidade, organização e melhoria contínua dentro da instituição.

## 📊 Conteúdo do Portal

O portal foi desenvolvido para apresentar de forma interativa toda a evolução do **Programa 5S** no Hospital Municipal Dr. Nestor Piva, reunindo informações institucionais, resultados das auditorias e ações de melhoria contínua.

### O portal contempla:

- 🏥 Apresentação do Programa 5S
- 📖 O que é o Programa 5S
- ⚙️ Como o 5S é aplicado no Hospital Municipal Dr. Nestor Piva
- 📅 Registro do Dia D do Programa
- 📊 Indicadores gerais e estatísticas do Programa
- 📋 Resultados completos da **1ª Auditoria 5S**
- 📈 Resultados completos da **2ª Auditoria 5S**
- 📉 Comparativo de evolução entre as auditorias
- 🏆 Ranking de conformidade dos setores
- 🥇 Sistema de certificações por faixa de conformidade
- 🎖️ Premiações e reconhecimentos obtidos pelos setores
- 📄 Certificados digitais de cada auditoria
- ⚡ Apresentação das ações de **Quick Wins**
- 🖼️ Galeria de imagens do Programa
- 📱 Interface totalmente responsiva para computadores, tablets e smartphones
- ✨ Animações, barras de progresso, contadores e elementos interativos em JavaScript
